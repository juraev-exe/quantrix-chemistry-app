About Quantrix

Quantrix is a student-centered chemistry platform designed to make middle school chemistry engaging, tactile, and intuitive.

Features include an interactive 118-element periodic table with real-time frequency audio synthesis, smart element search, keyboard navigation, molarity calculator, element quiz challenge, and solution concentration tools.
