How to Add New Student Projects

This dashboard automatically detects and registers new student projects. Simply create a new folder inside Projects/ following the naming standard:

Projects/StudentName_Subject_ProjectNumber/

Inside that folder, include an index.html entry point and a project.json file with project details:

{ "studentName": "Student Name", "subject": "Physics", "projectNumber": "P3", "title": "Interactive Lab Title", "status": "In Progress", "description": "Short summary of project scope...", "tags": ["Topic 1", "Topic 2"], "lastUpdated": "2026-09-13" }
