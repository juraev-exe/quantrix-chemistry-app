About Quantrix

Quantrix is a student-centered chemistry platform designed to make middle school chemistry engaging, tactile, and intuitive.

Features include an interactive 118-element periodic table with real-time frequency synthesis via the Web Audio API, element search, keyboard navigation, molarity calculator, element quiz, and solution concentration tools.
