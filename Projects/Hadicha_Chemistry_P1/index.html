About Quantrix

Quantrix is a secondary chemistry platform designed to make chemical intuition intuitive, tactile, and mathematically grounded.

Features include an interactive 118-element periodic table with calibrated acoustic frequency synthesis via the Web Audio API, real-time element search, keyboard navigation, molarity calculator, element quiz, and solution concentration tools.

Developed by Hadicha Ibragimova, student at MMT School.
